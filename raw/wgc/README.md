# WGC 엑셀을 올리는 폴더

World Gold Council 엑셀은 로그인해야 받을 수 있어서 사람이 직접 올려야 합니다.

1. <https://www.gold.org/goldhub/data/gold-reserves-by-country> 에 로그인합니다 (가입 무료).
2. 아래 파일을 내려받습니다. 이름은 달마다 조금씩 바뀌며, 바꾸지 않고 그대로 올리면 됩니다.
   - `Changes_latest_as_of_….xlsx` — 월간·연간 증감 (2002년부터)
   - `Quarterly_gold_and_FX_Reserves_….xlsx` — 분기별 보유량 (2000년부터)
   - `World_official_gold_holdings_as_of_….xlsx` — 최신 보유량과 외환보유액 대비 비중
3. 이 폴더에 올립니다. GitHub 화면에서 **Add file → Upload files** 로 끌어다 놓고 **Commit changes** 를 누릅니다.
4. 몇 분 뒤 사이트에 반영됩니다. 읽힌 결과는 사이트의 **자료 현황** 화면에서 시트별로 확인할 수 있습니다.

새 파일을 올릴 때 지난달 파일은 지워도 되고 그대로 두어도 됩니다. 같은 기간의 값은 이름순으로 뒤에 오는 파일이 우선합니다.
매달 10일 무렵 새 판이 나옵니다.
